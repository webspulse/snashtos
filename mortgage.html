Custom Values

Below are the custom values included in the Mortgage GoHighLevel Snapshot. These values are designed to simplify the customization process and ensure personalized communication for mortgage leads.

Custom Values List

1. Apply Now Link {{ custom_values.apply_now_link }} Purpose: Directs leads to the mortgage application form.

2. Calendar ID {{ custom_values.calendar_id }} Purpose: Connects to the loan officer's calendar for easy appointment scheduling.

3. Company Address {{ custom_values.company_address }} Purpose: Displays the company’s physical address for credibility and contact.

4. Company License Number {{ custom_values.company_license_number }} Purpose: Provides the official mortgage license number for compliance.

5. Company Name {{ custom_values.company_name }} Purpose: Auto-fills the company name in communications.

6. Facebook Page {{ custom_values.facebook_page }} Purpose: Links to the company's Facebook profile for social proof.

7. From Email {{ custom_values.from_email }} Purpose: Sets the sender email for campaigns and automations.

8. Instagram Page {{ custom_values.instagram_page }} Purpose: Links to the company’s Instagram profile for additional social presence.

9. License Number {{ custom_values.license_number }} Purpose: Displays the company’s mortgage license information for trust and legality.

10. Loan Officer Favicon Logo {{ custom_values.lo_favicon_logo }} Purpose: Displays a customized favicon on web pages.

11. Loan Officer Logo {{ custom_values.lo_logo }} Purpose: Provides the loan officer's logo for branding.

12. Loan Officer Website URL {{ custom_values.lo_website_url }} Purpose: Directs leads to the loan officer's website for additional information.

13. Mortgage Loan Officer Phone Number {{ custom_values.mlo_phone_number }} Purpose: Displays the mortgage loan officer's contact number for leads to call.

14. Mortgage Loan Officer First Name {{ custom_values.mlo_first_name }} Purpose: Adds personalization to messages by addressing leads with the officer's first name.

15. Mortgage Loan Officer Full Name {{ custom_values.mlo_full_name }} Purpose: Personalizes communications with the officer’s full name.

16. OpenAI Prompt {{ custom_values.openai_prompt }} Purpose: Custom AI prompt for automated chatbots and AI-enhanced content.

17. Reactivation Message {{ custom_values.reactivation_message }} Purpose: Predefined reactivation message for following up with inactive leads.

18. Review Link {{ custom_values.review_link }} Purpose: Provides a direct link for clients to leave a review.

19. Robot Webhook {{ custom_values.robot_webhook }} Purpose: Webhook URL for integrating with chatbots or automation tools.

20. Robot Webhook - Nonbooking {{ custom_values.robot_webhook_nonbooking }} Purpose: Separate webhook for handling non-booking scenarios.

21. TikTok Page {{ custom_values.tiktok_page }} Purpose: Links to the company’s TikTok profile for engaging content.

22. YouTube Page {{ custom_values.youtube }} Purpose: Links to the company’s YouTube channel for educational or promotional videos.

Implementation Instructions

Navigate to the "Settings" area in your GoHighLevel account.

Select "Custom Values."

Add or modify the provided custom values to match your business information.

Utilize these values in your email campaigns, SMS messages, landing pages, and automations for improved personalization and streamlined updates.
